# Manual workout logging

The exercise picker searches canonical names and active aliases. Muscle filters use reviewed primary groups for the built-in catalog. Custom entries and catalog entries without reviewed metadata appear under Unclassified and remain searchable under All. A catalog entry can be added once to an open workout.

Log a set to see the most recent comparable performed set for the same exercise, including an assisted label when applicable. A complete set in the current workout takes precedence. Earlier finished workouts and back-dated logs are eligible. Missing reps, missing weighted loads and incompatible set formats cannot prefill the form. For weighted exercises, use the same equipment and load convention when comparing. Repeat previous set fills the draft. Saving records a performed set. Undo removes the new set through the existing sync-aware deletion path.

## Manual checks

1. Start or resume a workout. Browse Legs, search for an exercise by a stored alias if available, then add it twice. Expect one entry and zero sets. Find a custom exercise under All or Unclassified.
2. Open Log a set on an exercise with history. Check the weight convention, reps and assistance label. Tap Repeat previous set, adjust the values and save. Expect one set. With no comparable history, expect blank inputs.
3. Tap Undo set. Expect the new set to disappear and the draft values to remain editable. Save again intentionally and expect one set.
4. In airplane mode, log a set and reopen the app. Reconnect in the foreground and check that the set restores once in a fresh workspace signed into the same synthetic account. A different account should have its own records.
5. Open Log chat and Coach. Expect their existing account, consent and response flow.
